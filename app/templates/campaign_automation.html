Before Turning Automation On

Recommended order:

1. Upload contacts.
2. Add email steps.
3. Generate drafts.
4. Review drafts.
5. Send a test email.
6. Approve drafts.
7. Set the automation start date.
8. Turn automation on.

How Send Days Work

Send Day controls when each email step should send.

Example:

Automation Start Date: September 1
Step 1, Send Day 1 → sends September 1
Step 2, Send Day 3 → sends September 3
Step 3, Send Day 7 → sends September 7

If the cron job misses a day, the app will catch up on due approved drafts the next time it runs, while still respecting the daily send limit.
