Before Turning Automation On

Confirm these items before using automation:

1. Contacts are uploaded or imported.
2. Email steps are created.
3. Drafts are generated.
4. Drafts are reviewed and approved.
5. Sender email is verified in SES.
6. DEMO_MODE is false if you want real sending.
7. Render Cron Job is configured with the correct CRON_SECRET.

How Send Days Work

If you set an Automation Start Date, that date becomes Day 1 for the campaign.

Example:
Automation Start Date: September 1
Step Day 1 sends on September 1.
Step Day 3 sends on September 3.
Step Day 7 sends on September 7.

If you leave Automation Start Date blank, each contact uses their own sequence start date, usually the upload/import date.
